# ClipFlow AI

An open-source Android video studio built with Kotlin, Jetpack Compose and AndroidX Media3.

## Current milestone

- Native Android project structure
- Video picker using Android's system document picker
- Local video preview using Media3 ExoPlayer
- GitHub Actions workflow for debug APK and release AAB builds
- MIT license

## Roadmap

1. Timeline editing: trim, split, join, text and filters
2. AI-assisted highlight detection and automatic captions
3. Export presets for vertical and landscape video
4. Official social publishing integrations where platform APIs permit

## Build

Push to `main` or open **Actions → Android Build → Run workflow**.

The workflow uploads APK and AAB files as a downloadable build artifact.
